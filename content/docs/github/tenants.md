# Tenants

**The tenants that live in Deevnet for good keep their code and documentation in their own
repositories, at [github.com/cdeever](https://github.com/cdeever).** Each is tracked in the
[Roadmap](/docs/roadmap/) because Deevnet builds and maintains it.
