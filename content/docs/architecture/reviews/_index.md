# Architecture Reviews

**A review assesses the site as it stands against a stated set of criteria, on a date.** It reads the
code, the inventory and the records, and reports what it finds, with evidence. Like a
[decision record](/docs/architecture/decisions/), it is point-in-time: it is not rewritten as the
site changes.

**A review decides nothing.** Its findings and recommendations are inputs. Each one that is acted on
closes through the usual records: an ADR for a decision, a change record for work on the site.
