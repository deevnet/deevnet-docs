# Projects

**Active projects, in detail.** A [Roadmap](/docs/roadmap/) item says what is intended and its
milestones; once work starts, its plan is written here: scope, reasoning, the work in each phase,
status, and the change records that carry it out. When a project is done, its plan moves to
[Completed Projects](/docs/completed/), and its roadmap item is removed.
