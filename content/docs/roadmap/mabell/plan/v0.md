# MaBell Project Plan v0: Foundation

**Plan:** [MaBell Bluetooth Gateway: Project Plan](/docs/roadmap/mabell/plan/) · **Next:** [v1: On the bench](/docs/roadmap/mabell/plan/v1/)

{{< overall-progress >}}

**Legend:** ✅ Complete | 🔄 In Progress | ⏳ Planned

Requirements, design and the first firmware: the base every prototype builds on. The firmware came
first so the prototypes have something to talk to the hardware. **Status:** done, 2026-10-10.

**Done when:**

- [x] Requirements, constraints and acceptance criteria are written, with a risk register. {{< added "2026-11-06" >}}
- [x] The system, power, audio and firmware design is finished, with a verification plan mapping requirements to tests. {{< added "2026-11-06" >}}
- [x] The firmware builds and runs on the ESP32: Bluetooth HFP, the call state machine, tone generation, NVS configuration and logging. {{< added "2026-11-06" >}}
- [x] MaBell is a Deevnet tenant: its state over MQTT, its events in the central log store, and a Grafana dashboard. {{< added "2026-11-06" >}}

**Not in v0:** any hardware beyond the ESP32 itself (v1 onward); firmware release tagging (v1).
