# MaBell Project Plan v4: Boxed and Installed

**Plan:** [MaBell Bluetooth Gateway: Project Plan](/docs/roadmap/mabell/plan/) · **Previous:** [v3: Line voltage and a real bell](/docs/roadmap/mabell/plan/v3/)

The end state: the gateway on its own circuit board, in an enclosure, installed at home and in
daily use. **Status:** planned. Its definition of done and tasks are written when it becomes
current.

## Scope

- **Circuit board:** schematic capture and layout in KiCad, built around the line interface chosen in v3, with test points and a programming header.
- **Revisions:** fabricate, assemble and bring up Rev A; fix what it shows in Rev B and later, until a board is electrically verified against the requirements.
- **Firmware:** retuned for the board, with the full set of functional sections passing again.
- **Enclosure:** designed (3D printed or fabricated), with connector placement, strain relief, and thermal and safety review.
- **Installed:** wired to the house phone and in daily use, with a long-run stability check.
- **Documentation:** the build, wiring, user and troubleshooting guides, and design notes and lessons learned.

**Not in v4:** building more units; MaBell is built once.
