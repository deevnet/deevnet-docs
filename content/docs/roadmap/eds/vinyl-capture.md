# EdS Vinyl Capture

Every record played is captured to FLAC, by itself, track by track, so the digital collection comes
to include what is held only on vinyl. A project and repository of its own, to come; its proposal is
EdS's [Capturing Vinyl](https://cdeever.github.io/eds/docs/architecture/proposals/capturing-vinyl/).

## Project Vision & Scope

A stub: the project is proposed, not decided. EdS listens and captures; eds-inventory knows what is
captured and what is missing.

**In Scope**
- Capturing each record played, a track already kept skipped, nobody pressing record

**Out of Scope**
- Naming the record: EdS's turntable driver and the inventory
